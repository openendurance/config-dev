# Generated

Agent-generated output for `config-dev`.

## What Belongs Here

Artifacts produced by automated analysis or transformation passes. These are outputs of generation workflows — they are not hand-authored and should not be hand-edited.

If you need to correct a generated artifact, re-run the originating process with corrected inputs. Manual edits will be overwritten the next time the generator runs.

## Adding New Generated Subdirectories

When a new generator produces output:

- Create a subdirectory named after the generator or workflow
- Add it to the contents table above
- Add a `README.md` to the subdirectory identifying the origin, output format, and regeneration instructions

## Update Contract

Do not hand-edit. Re-run the originating generator to regenerate. If a workflow's output format changes, update the subdirectory README accordingly.
